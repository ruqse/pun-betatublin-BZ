# Input data

Every file here is an input to `scripts/` or `pipeline/`. `MD5SUMS.txt` lists a checksum for each one; check them with `md5sum -c data/MD5SUMS.txt` from the repository root.

The scripts produce derived files in `results/`, `figures/` and `tables/`. Nothing here is generated by `scripts/run_all.sh`.

## Haplotype FASTA headers

Each header carries the pbaa cluster metadata, for example:

```
>Pun-bt-B-Susceptible_cluster-0_ReadCount-20318 uchime_score:-1 ... cluster_freq:0.130699 diversity:0.00212244 avg_quality:48.2022 ... seq_length:7866 filters:none
```

| Field | Meaning |
|---|---|
| `ReadCount` | reads assigned to the cluster |
| `cluster_freq` | the cluster's share of the sample's clustered reads |
| `uchime_score` | pbaa chimera score; -1 means the cluster was not flagged |

Five clusters have a positive `uchime_score`: Pun-bt-A Resistant cluster 12, and Pun-bt-C Susceptible clusters 31, 33, 34 and 35. They are kept in the FASTA files for completeness. The haplotype-diversity, meta-haplotype and G_ST analyses exclude them.

Every CDS in `haplotype_cds/` is written in coding orientation.

## Steps outside the scripted pipeline

These steps are documented here so the record is complete.

1. **VEP annotation.** The VEP tables in `variants/reads_annot/` came from the WormBase ParaSite VEP web interface. `pipeline/` can run VEP 111 offline (`--run_vep`) from the WBPS19 GFF3 and genome.
2. **CDS protein alignments.** Haplotype CDS from `pipeline/` EXTRACT_CDS were translated and aligned with the reference protein outside the scripted pipeline. For 242 of the 243 haplotypes, the ungapped protein in `cds_alignments/` is identical to the standard-code translation of the pipeline CDS (checked by `pipeline/tests/compare_to_published.py`).

   The exception is Pun-bt-B Susceptible cluster-24 (631 reads). Its pbaa consensus has a 1-nt deletion near codon 284, so the raw translation is frameshifted; in the alignment the frame was restored by hand, and the affected residue is written `?`. Table S2 lists it as `L284?` in 0.41% of Farm-S reads.
